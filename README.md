# Service Air Eastern Shore Website Concept

Standalone Next.js website concept prepared for outreach.

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Project notes

- Prospect: http://www.serviceaireasternshore.com/
- Official logo and homepage photo are saved locally in `public/brand` and `public/hero`.
- Business details and theme are in `src/config/site.config.ts`; confirm with the company before publishing.
- The contact form is a preview and does not send submissions. Maps use OpenStreetMap tiles and need internet access.
